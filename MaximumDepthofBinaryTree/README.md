# LeetCode 104: Maximum Depth of Binary Tree

## 問題定義

### 原始問題（英文）

Given the root of a binary tree, return its maximum depth.

A binary tree's maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.

**Example 1:**
```
    3
   / \
  9  20
    /  \
   15   7

Input: root = [3,9,20,null,null,15,7]
Output: 3
```

**Example 2:**
```
Input: root = [1,null,2]
Output: 2
```

**Constraints:**
- The number of nodes in the tree is in the range [0, 10^4]
- -100 <= Node.val <= 100

### 問題翻譯（繁體中文）

給定二元樹的根節點，返回其最大深度。

二元樹的最大深度是從根節點到最遠葉節點的最長路徑上的節點數量。

**範例 1：**
```
    3
   / \
  9  20
    /  \
   15   7

輸入：root = [3,9,20,null,null,15,7]
輸出：3
```

**範例 2：**
```
輸入：root = [1,null,2]
輸出：2
```

**限制條件：**
- 樹中節點數量的範圍為 [0, 10^4]
- -100 <= Node.val <= 100

## 解題思路

### 方法一：DFS 遞迴法

**核心思想：**
樹的深度 = 1 + max(左子樹深度, 右子樹深度)

**步驟：**
1. 基礎情況：空節點深度為 0
2. 遞迴計算左子樹和右子樹的深度
3. 返回較大的深度 + 1（當前節點）

**視覺化：**
```
        3          深度 3
       / \
      9  20        深度 2
        /  \
       15   7      深度 1

計算過程：
- maxDepth(15) = 1
- maxDepth(7) = 1
- maxDepth(20) = 1 + max(1, 1) = 2
- maxDepth(9) = 1
- maxDepth(3) = 1 + max(1, 2) = 3
```

### 方法二：BFS 層序遍歷

**核心思想：**
使用佇列進行層序遍歷，記錄層數

**步驟：**
1. 使用佇列儲存每一層的節點
2. 逐層處理，每處理完一層，深度 +1
3. 返回總層數

### 方法三：DFS 迭代法（使用堆疊）

**核心思想：**
使用堆疊模擬遞迴，同時記錄節點深度

**步驟：**
1. 使用堆疊儲存 (節點, 深度) 對
2. 遍歷過程中更新最大深度
3. 返回最大深度

## 複雜度分析

### DFS 遞迴法
- **時間複雜度**：O(n)，其中 n 是節點數，需要訪問每個節點一次
- **空間複雜度**：O(h)，其中 h 是樹的高度，最壞情況下為 O(n)（退化為鏈結串列）

### BFS 層序遍歷
- **時間複雜度**：O(n)，需要訪問每個節點一次
- **空間複雜度**：O(w)，其中 w 是樹的最大寬度，最壞情況下為 O(n)

### DFS 迭代法
- **時間複雜度**：O(n)，需要訪問每個節點一次
- **空間複雜度**：O(h)，堆疊的最大深度

## 關鍵要點

1. **遞迴思維**：樹的問題常常可以用遞迴解決
2. **邊界條件**：空節點的深度為 0
3. **選擇合適方法**：DFS 遞迴最簡潔，BFS 適合層級相關問題
4. **空間考量**：遞迴有堆疊溢位風險，但代碼更簡潔

## 測試說明

測試涵蓋：
- 空樹
- 單節點樹
- 完全二元樹
- 不平衡樹（偏左或偏右）
- 大型樹的效能測試
