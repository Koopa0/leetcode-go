# LeetCode 206: Reverse Linked List

## 問題定義

### 原始問題（英文）

Given the head of a singly linked list, reverse the list, and return the reversed list.

**Example 1:**
```
Input: head = [1,2,3,4,5]
Output: [5,4,3,2,1]
```

**Example 2:**
```
Input: head = [1,2]
Output: [2,1]
```

**Example 3:**
```
Input: head = []
Output: []
```

**Constraints:**
- The number of nodes in the list is the range [0, 5000]
- -5000 <= Node.val <= 5000

**Follow up:** A linked list can be reversed either iteratively or recursively. Could you implement both?

### 問題翻譯（繁體中文）

給定單向鏈結串列的頭節點，反轉該鏈結串列，並返回反轉後的鏈結串列。

**範例 1：**
```
輸入：head = [1,2,3,4,5]
輸出：[5,4,3,2,1]
```

**範例 2：**
```
輸入：head = [1,2]
輸出：[2,1]
```

**範例 3：**
```
輸入：head = []
輸出：[]
```

**限制條件：**
- 鏈結串列的節點數量範圍為 [0, 5000]
- -5000 <= Node.val <= 5000

**進階：** 鏈結串列可以使用迭代或遞迴方式反轉。你能實作這兩種方法嗎？

## 解題思路

### 方法一：迭代法

使用三個指標來追蹤：
- `prev`：前一個節點（初始為 nil）
- `curr`：當前節點（初始為 head）
- `next`：下一個節點（暫存用）

**步驟：**
1. 遍歷鏈結串列
2. 暫存下一個節點
3. 將當前節點的 next 指向前一個節點
4. 移動指標前進

**視覺化：**
```
原始: 1 -> 2 -> 3 -> 4 -> 5 -> nil
步驟1: nil <- 1    2 -> 3 -> 4 -> 5 -> nil
步驟2: nil <- 1 <- 2    3 -> 4 -> 5 -> nil
步驟3: nil <- 1 <- 2 <- 3    4 -> 5 -> nil
步驟4: nil <- 1 <- 2 <- 3 <- 4    5 -> nil
步驟5: nil <- 1 <- 2 <- 3 <- 4 <- 5
```

### 方法二：遞迴法

**核心思想：**
- 反轉從第二個節點開始的子鏈結串列
- 將第二個節點的 next 指向第一個節點
- 將第一個節點的 next 設為 nil

**遞迴終止條件：**
- 空鏈結串列或只有一個節點

## 複雜度分析

### 迭代法
- **時間複雜度**：O(n)，其中 n 是鏈結串列的節點數，需要遍歷整個鏈結串列
- **空間複雜度**：O(1)，只使用固定數量的額外空間

### 遞迴法
- **時間複雜度**：O(n)，需要訪問每個節點一次
- **空間複雜度**：O(n)，遞迴呼叫堆疊的深度

## 關鍵要點

1. **指標操作**：需要小心處理指標的更新順序，避免斷鏈
2. **邊界情況**：空鏈結串列和單節點鏈結串列
3. **空間權衡**：迭代法空間複雜度更優，遞迴法代碼更簡潔

## 測試說明

- 單節點鏈結串列
- 多節點鏈結串列
- 效能測試（大型鏈結串列）
